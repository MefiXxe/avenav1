Tu web. Tu enlace.

No necesitas instalar Node, React ni una base de datos.

Actualizar tu web actual

  1. Revisa tus cambios con Ver vista previa.
  2. Descarga config.js con el botón de abajo.
  3. En tu repositorio de GitHub, entra en Add file → Upload files y arrastra el nuevo config.js a la raíz.
  4. Pulsa Commit changes. Tu alojamiento conectado a GitHub actualizará la web.

Las imágenes que subes aquí quedan incluidas en config.js. No tienes que subirlas por separado.

Publicar por primera vez

Descarga toda la página con tus cambios y sigue la guía incluida. El ZIP contiene todos los archivos que debes subir.
