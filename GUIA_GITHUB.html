QUINUA CRUNCH · VERSIÓN 4

Cómo verla, personalizarla
y publicarla gratis.

GitHub guarda tus archivos. Cloudflare Pages publica la web y genera el enlace. El proyecto está hecho con HTML, CSS y JavaScript: no requiere instalar Node ni ejecutar un servidor propio.

1. Descomprime y revisa la página

  1. Descarga Quinoa_Crunch_Web_v4.zip.
  2. En Windows, haz clic derecho sobre el ZIP → Extraer todo.
  3. Abre la carpeta extraída y haz doble clic en index.html. Se abrirá con tu navegador.
  4. Comprueba los sabores, las flechas, los iconos y el avance automático.

Abrir el archivo en tu computadora sirve para revisarlo. Todavía no crea una dirección pública para compartir.

2. Sube los archivos a GitHub

  1. Entra en github.com y crea tu cuenta o inicia sesión.
  2. Pulsa + → New repository.
  3. Escribe quinua-crunch como nombre. Selecciona Public y activa Add a README file.
  4. Pulsa Create repository.
  5. Dentro del repositorio, abre Add file → Upload files.
  6. Arrastra todo el contenido descomprimido, incluida la carpeta assets. No subas solamente el ZIP.
  7. Confirma la subida en la rama main, con un mensaje como Primera versión de Quinua Crunch.
Al abrir el repositorio debes ver index.html, config.js, admin.html y la carpeta assets al mismo nivel. No deben quedar dentro de otra carpeta contenedora.

3. Publica con Cloudflare Pages

  1. Entra en Cloudflare, crea tu cuenta y usa el plan gratuito.
  2. Abre Workers & Pages → Create application → Pages.
  3. Elige Connect to Git o Import an existing Git repository, según lo que muestre el panel.
  4. Conecta GitHub, permite el acceso al repositorio quinua-crunch y selecciónalo.
  5. En la configuración del proyecto usa estos valores:
CampoValor para esta web
Project nameEl nombre que quieras para el enlace
Production branchmain
Framework presetNone
Build commandexit 0
Build output directory/ · raíz del repositorio, donde está index.html
Root directoryDéjalo en su valor predeterminado
  1. Pulsa Save and Deploy y espera a que el estado indique que terminó correctamente.
  2. Abre la dirección de producción que te muestra Cloudflare y compártela.

El enlace tendrá una forma parecida a https://nombre-elegido.pages.dev. Es solo un ejemplo: usa la dirección real que te entregue el panel. No necesitas comprar un dominio para empezar.

Después de conectar el repositorio, Cloudflare vuelve a publicar los cambios que confirmes en GitHub.

4. Dónde está el menú personalizable

Es una página separada llamada admin.html. No aparece en el menú que ven los clientes.

Qué quieres abrirDirección o archivo
Página principalLa dirección normal que te dio Cloudflare
Menú personalizableLa misma dirección + /admin.html
Ejemplo de configuradorhttps://nombre-elegido.pages.dev/admin.html
Antes de publicarPuedes abrir admin.html dentro de la carpeta extraída

Para usar la vista previa y la descarga del ZIP con todas las funciones del navegador, es preferible abrir el panel desde la página alojada. No necesitas subir la web a ChatGPT para ponerla en funcionamiento.

Avance automático

En Marca y portada → Avance de los sabores, elige Automática o Manual y un intervalo entre 3 y 30 segundos. El valor inicial es 6 segundos. La portada avanza sola y no muestra un botón de pausa. El carrusel se detiene temporalmente mientras muestra detalles o fotografías y cuando deja de estar visible. Si su navegador pide reducir el movimiento, empieza en modo manual.

Colores e iconos por sabor

En Productos, abre una barra y cambia Color de fondo, Color del texto y Color de detalles e iconos. La portada usa esa paleta al mostrar ese sabor. En Icono del sabor puedes elegir quinua, chocolate, avena, hoja o barrita.

Imagen y tamaño

Usa Subir imagen para el producto recortado. El control Tamaño de imagen ajusta su presencia en la portada. Los tres empaques incluidos tienen escalas distintas para compensar los márgenes y proporciones originales. Subir fotografía configura la foto con fondo que aparece al pulsar Ver fotografía.

WhatsApp

En Contacto, ingresa tu número con código de país. En Perú: 51 + tus 9 dígitos. Prueba el enlace antes de publicar. El número se entrega vacío para que lo completes con el tuyo.

6. Cómo publicar los cambios del panel

  1. Edita tus datos y revisa Ver vista previa.
  2. Pulsa Descargar config.js.
  3. Abre tu repositorio en GitHub → Add file → Upload files.
  4. Sube el nuevo config.js a la raíz, reemplazando el anterior, y confirma el cambio en main.
  5. Cloudflare actualizará la página automáticamente.
  6. Abre tu dirección normal, sin ?preview=1, para verificar lo que verán los visitantes.
Guardar borrador no publica. El panel guarda los cambios en ese navegador. Solo se comparten al subir la configuración a GitHub. El panel no tiene acceso a tu cuenta de GitHub ni incluye una contraseña de administrador ficticia.
